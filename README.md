# DAK 4.6.0

Обновления приложения DAK. Автосмена портов теперь работает и на сервере со входом в России (у связи с ним свой постоянный порт). Телефон сам забирает новые порты: при подключении и каждые 6 часов. На карточке сервера видно, когда порты менялись в последний раз. Окно «Сменить порты» помещается на экран со всеми протоколами.
