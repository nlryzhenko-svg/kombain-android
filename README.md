# DAK 4.2.0

Обновления приложения DAK. Что нового:
• Вход по отпечатку: DAK открывается только после отпечатка, лица или PIN телефона (Настройки → Безопасность). VPN при этом работает как обычно.
• Проверка утечек (Ещё → Проверка утечек): не виден ли ваш настоящий IP мимо VPN — адрес, IPv6, DNS, WebRTC, браузеры.
